# "Programa - Cálculo de Média - Consumo de Energia Elétrica de um aparelho doméstico"

Este projeto em Python,foi criado para Calcular o Consumo Médio que um aparelho doméstico consome com dados fornecidos pelo usuário.

Ciclo do Programa **Entrada - Processamento - Saída**

O programa solicita ao usuário: *nome do aparelho utilizado* , a *Potência utilizada (em Watts)* e *o tempo que o aparelho funciona por dia*. 
Através dos dados fornecidos pelo usuário o programa fornece os calculos do consumo diário, consumo mensal e custo mensal do aparelho para o cliente.
